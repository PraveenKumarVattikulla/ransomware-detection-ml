# Ransomware Detection using Deep Learning

## 📌 Project Overview
This project implements a deep learning-based ransomware detection system for:
- Binary Classification (Ransomware vs Benign)
- Multi-class Classification (10 Ransomware Families)

The system analyzes 80+ behavioral features to detect malicious activity patterns.

---

## 📊 Dataset Details
- 300,000+ samples
- 80+ behavioral features
- Multi-class classification (10 ransomware families)

---

## 🧠 Models Implemented
- LSTM
- Bi-LSTM
- GRU
- MLP
- XGBoost

---

## 📈 Results
- 99% accuracy in binary classification
- High multi-class accuracy across ransomware families
- Evaluated using Accuracy, Precision, Recall, and F1-Score
